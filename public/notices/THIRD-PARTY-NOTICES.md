# TypeNext third-party notices

Audited for the v0.1.0 release on 6 October 2026. TypeNext-owned work is MIT; the components below retain their own terms. Full license files are included beside this notice. The [npm inventory](npm-inventory.json) records exact installed versions, upstream sources and license-text hashes; [NPM-THIRD-PARTY-LICENSES.txt](NPM-THIRD-PARTY-LICENSES.txt) preserves complete, deduplicated license texts for the 137 installed non-development npm packages.

The npm inventory is deliberately conservative: installing Transformers.js and PDF.js also installs supporting Node-only packages. The Tauri/browser app does **not** package Node.js, `onnxruntime-node`, sharp/libvips or native canvas libraries. Their presence in the installed inventory does not describe the app's runtime. Build-tool dependencies are not redistributed as application code; any helper code that enters the production dependency set is covered by its package notice.

`guid-typescript` 1.0.9 declares ISC in its published package metadata but ships no standalone license/copyright file; the corresponding npm collection entry records the author exactly as supplied and reproduces the ISC reference terms without inventing a copyright year. This metadata-only provenance is explicitly distinguished from a copied upstream license file.

Their actual package licenses, including their copyright/reserved-name notices, are copied unchanged. Miracode's bundled license matches its official v1.0 license after line-ending normalization.

Fonts keep OFL-1.1 rather than becoming MIT. The app uses the supplied font binaries/subsets without modifying or renaming them. Font licenses permit bundling with the app while preserving their terms; reserved names and the prohibition on selling a font by itself remain applicable. Documents written with these fonts do not inherit the font license.

**Segoe UI, Tahoma and Times New Roman are operating-system font choices, not redistributed assets.** Other fallback font names similarly refer to installed system fonts. The user's `Fonts/` directory is not changed or included in release bundles. Fontsource assets and notices are self-hosted; writing does not load fonts from Google Fonts or another CDN.

The current TypeNext app/brand icon is a project asset covered by the project's license. Lucide attribution applies to the Lucide UI icons; it does not claim Lucide authored or endorsed the project branding. Third-party product/font names identify their sources and imply no endorsement.

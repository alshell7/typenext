# Licensing and attribution

TypeNext-owned code and documentation are licensed under the [MIT License](../LICENSE.md), as authorized by the project owner. Third-party code, fonts, runtimes and model artifacts retain their upstream licenses. Their license texts and attribution are distributed under `public/notices` and `public/fonts`.

## Template provenance

The original repository included an AGPL-labelled Tauri template license and archived template documentation. The identifiable upstream is [dannysmith/tauri-template](https://github.com/dannysmith/tauri-template), including the retained architecture guide and README wording. Its author changed the template license to MIT in [commit d77b088cf647bad99e27465e48e414ef5eb474bc, 16 October 2025](https://github.com/dannysmith/tauri-template/commit/d77b088cf647bad99e27465e48e414ef5eb474bc). The [current upstream MIT license](https://github.com/dannysmith/tauri-template/blob/d77b088cf647bad99e27465e48e414ef5eb474bc/LICENSE.md) is retained verbatim at [Tauri-Template-LICENSE.txt](../public/notices/Tauri-Template-LICENSE.txt).

This release uses that upstream MIT grant and the owner's MIT grant for TypeNext-owned work. It does not change the licenses of independent dependencies or claim ownership of the template authors' work. Historical license references in archived template material describe the older template release.

## Release notice layout

Release artifacts must retain `LICENSE.md`, this document, `public/notices`, and the bundled font license texts. The release workflow also collects the licenses and notices of the native Rust dependencies resolved for each target. Optional SmolLM2 and Whistle weights are downloaded from their upstream repositories after an explicit action; they are not included in TypeNext installers.

The [bundled third-party notices](../public/notices/THIRD-PARTY-NOTICES.md) give the component and font inventory. [npm-inventory.json](../public/notices/npm-inventory.json) records 137 installed non-development npm packages, their exact versions, upstream URLs, license expressions, source-text provenance and SHA-256 keys. [NPM-THIRD-PARTY-LICENSES.txt](../public/notices/NPM-THIRD-PARTY-LICENSES.txt) retains 79 distinct complete license texts without repeating identical text. This inventory is conservative; a package installed alongside a dependency is not automatically part of the app's browser bundle.

The release collector in `scripts/release/collect-rust-notices.mjs` uses locked, target-filtered Cargo metadata to retain each native crate's declared license expression, source, authors, and published LICENSE/COPYING/NOTICE files. Target-specific native notices belong beside the committed notices in every Windows x64, macOS arm64 and macOS x64 release. A missing full native license text fails collection rather than silently declaring the release complete.

## Attribution boundaries and recorded gaps

- The current project icon and TypeNext-authored assets fall within the project's MIT scope. Lucide UI icons remain ISC, including MIT terms for Feather-derived portions; their complete upstream notice is preserved. Product/font names identify sources and imply no endorsement.
- JSZip's MIT option and Tauri's MIT option are selected; the original dual-license declarations remain recorded. Pako retains both MIT and Zlib notices. Components are not relabelled as MIT merely because TypeNext is MIT.
- `guid-typescript` 1.0.9 declares ISC in npm metadata but supplies no standalone license or copyright file. The npm collection marks this explicitly and retains the upstream author plus standard ISC reference terms; it does not invent a copyright year or present a reference as a copied source file.
- Node-only sharp/libvips, `onnxruntime-node` and native canvas packages can be installed with development dependencies. They are not packaged in the Tauri/browser application. Their installed metadata appears conservatively in the inventory and must not be mistaken for an app runtime dependency list.
- The missing independent license declaration in the pinned ONNX conversion is documented above. Model weights are not being republished as TypeNext release assets. Any future bundled or independently republished model should receive a fresh provenance audit rather than reuse an inferred license label.

## Native corresponding source

Native dependencies retain the license expressions declared by their locked upstream packages, including MPL-2.0 for several support crates. Each platform's release includes the complete published source of its MPL dependencies under `third-party-notices/native-<platform>/<crate>-<version>/source/`, alongside the license and target inventory. These source files are unmodified and retain their own terms; they do not change the MIT license of TypeNext-owned work.

The [selectors source-availability record](../public/notices/native-source-licenses/selectors-0.24.0/SOURCE-AVAILABILITY.md) identifies its exact public archive, locked checksum and upstream commit. Recipients can obtain the corresponding selectors source directly in `third-party-notices/native-<platform>/selectors-0.24.0/source/` in the installed resources or application archive. The [reviewed native license records](../public/notices/native-source-licenses/README.md) also distinguish complete copied upstream texts from packages that declare a standard license by reference; no copyright owner or year is invented for those packages.

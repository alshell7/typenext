# TypeNext 0.2.0

You write. AI suggests. This release makes the editor richer, makes suggestions understand your sources by meaning, and adds long dictation on your device. Everything new that touches your notes runs on your computer unless you turn on a service.

**Writing**

- Notes start at once: Ctrl/⌘ N and type. The first line becomes the title until you type one.
- A real Markdown editor: live bullets, task boxes and tables. Tab moves between table cells and indents list items. Enter continues a list.
- The `/` insert menu adds headings, lists, tables, code, links, dates and your own snippets. You can change the trigger character or turn the menu off.
- `[[Note links]]` complete note titles, show a hover card, and open with a Ctrl/⌘ click. A missing note can be created from its link. Web links show a preview card.
- Writing flow: a format bar on selection, smart typography (`--` becomes —), typewriter scrolling, paragraph or sentence focus, and a pasted web address becomes a link with the page title.
- A quiet outline in the margin, the notes that link to the current note, reading time and an optional daily word goal.
- The command palette (Ctrl/⌘ P) finds notes, headings in the note and every action.
- Three zen levels: hide the side panels, hide the toolbars, or full screen. The note graph (Ctrl/⌘ Shift G) shows how notes and contexts connect.

**Suggestions**

- Semantic search with Google EmbeddingGemma 2, beside BM25. In the desktop app, TypeNext downloads a pinned llama.cpp runtime and the model, checks each file and runs it on your computer. It also understands images, audio and video in your references.
- Suggestions follow the structure at the cursor: a heading stays a heading, a list item stays one item, a table cell gets a few words. Every suggestion shows the reference it came from.
- Suggestions wait while you type fast and come sooner at a pause. You can set the delays in Preferences → Suggestions → Timing.
- Cloudflare Workers AI is a new external provider. OpenAI, Anthropic and Cloudflare have a model list to choose from.
- Web facts (opt-in): select text, press Ctrl/⌘ Shift K, and insert a fact with its source from an OpenAI web search.

**Dictation**

- Fluid Speech Mini by FluidVoice (CC BY 4.0) for long English dictation in the desktop app, through a pinned parakeet.cpp runtime. Finished phrases enter the note at each pause.
- A small chip at the cursor shows the level, the time and the state. It never covers your text or takes the focus. Voice commands add punctuation, lines and list items. Dictation can stop by itself after silence.
- Whistle stays the small default (about 17 MB, 7 languages, clips of up to 30 seconds).

**Sync and setup**

- Optional Git sync keeps every note as a Markdown file in a repository of your choice, with the Git installed on your computer. When both sides change, both versions are kept.
- If Hugging Face asks for a sign-in for a model download, TypeNext shows a short guide and keeps the read token only for huggingface.co.
- New Preferences and Contexts screens. On macOS, the window uses the native traffic lights.

Packaging is the same as in 0.1.3: unsigned Windows binaries and ad-hoc-signed Mac bundles, so the system may show its normal trust prompt. Semantic search and Fluid Speech Mini need the desktop app and a one-time download. Model output is optional and can be wrong; check facts before you rely on them.

# TypeNext 0.3.0

TypeNext now keeps itself up to date, and the window looks right again on macOS.

**Updates inside the app**

- TypeNext checks the GitHub releases shortly after launch and every six hours. A new version downloads quietly in the background and is checked against the TypeNext signing key before it can install.
- A small notice shows when the update is ready, with **What’s new**, **Later** and **Restart to update**. Your notes are saved first. Nothing restarts without your choice.
- **Preferences → Updates** shows your version, **Check now**, and switches for automatic checks and background downloads. The command palette has **Check for updates**.
- The notice stays hidden in zen mode and while a dialog is open.

**Fixes**

- macOS: the sidebar subtitle "a place for your words" no longer overlaps the TypeNext name below the window buttons.
- The colour palette cards in **Preferences → Writing** have equal sizes and line up again.
- Messages float above the status bar instead of covering it, and close sooner.
- A narrow page keeps the word count and the save state on one line, and a long note title ends with an ellipsis.

**Update from 0.2.0**

Version 0.2.0 cannot update itself. Download 0.3.0 once from the releases page. From 0.3.0 on, updates install from inside the app.

Packaging is the same as in 0.2.0: unsigned Windows binaries and ad-hoc-signed Mac bundles, so the system may show its normal trust prompt for the first install. In-app updates are signed separately with the TypeNext update key.

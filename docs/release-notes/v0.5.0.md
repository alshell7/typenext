# TypeNext 0.5.0

Use one notebook on every device. Cloud sync keeps notes, folders, tags, workspaces, contexts and preferences the same everywhere, end-to-end encrypted with a key only you know.

**Cloud sync**

- Sync through a database in your own account: **Neon Postgres** or **Cloudflare D1**, or both at once (**Preferences → Cloud sync**).
- Everything is encrypted on your device before it leaves (AES-256-GCM). The database sees only random ids, times and ciphertext: never a title, a word of a note or a device name.
- Choose a sync key once per device. Three recovery keys can reset it if you forget it. Change the key or make new recovery keys at any time.
- **Live updates** with Neon Realtime: changes from other devices arrive within a second. Or sync on a schedule, or only when you ask.
- Choose what syncs: notes, organization, contexts and preferences, all workspaces or only some. API keys, file paths, Git folders and local model servers always stay on the device.

**Writing on two devices**

- **Devices** shows every device of the notebook, which are active and which note each has open. Remove a lost device and it forgets the key.
- The toolbar shows when another device has the same note open, or is writing in it. Edits then travel within a second.
- Changes to different words merge, word by word. When two devices change the same words at once, both versions are kept. Nothing is lost.
- Notes linked to files on another computer can be mapped to the same files here.

**Improvements**

- Changes that arrive in the open note keep your cursor and selection where they are.
- **Preferences → Sync** is now **Git sync**.

**Update from 0.4.0**

0.4.0 updates itself: a notice offers **Restart to update** when 0.5.0 has downloaded. Packaging is the same as in 0.4.0: unsigned Windows binaries and ad-hoc-signed Mac bundles. Updates are checked against the TypeNext update key before they install.

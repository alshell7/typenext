# TypeNext 0.1.1

The first public TypeNext release: a local-first Markdown notebook for Windows x64, Apple Silicon Macs and Intel Macs. TypeNext-owned code is released under MIT; included dependencies retain their upstream licenses.

- A quiet, tabbed writing space with neutral dark and light palettes, custom colours, adjustable fonts and a focus mode.
- Local autosave, recent notes, Markdown file import/export, and recovery from a valid saved backup. See the reliability documentation for the remaining unsaved-edit window.
- Reusable named context packages containing documents, PDFs, text, Markdown, websites or live links to other notes. Several packages can inform one note, and individual sources can be excluded.
- A shipped fictional Bramble House sample demonstrates context-grounded offline suggestions. The default local recall/starter engine needs no API key, model download or server.
- Ctrl/Cmd+Space offers suggestions at the cursor. Hosted manual choices provide up to three fresh alternatives from one request; Tab accepts the preview and undo restores the writing.
- Optional downloaded SmolLM2 suggestions, a loopback local model server, or deliberately activated continuous external suggestions through OpenRouter, OpenAI, Anthropic or a custom endpoint. A local failure never switches to a hosted provider.
- Offline Whistle dictation after an explicit model download: Ctrl/Cmd+Shift+D starts/stops recording, microphone selection is available, typing can continue, and the transcript is inserted at its tracked position before suggestions resume. Recording is limited to 30 seconds; failed insertions remain recoverable.

Windows downloads include a setup EXE, MSI and a portable ZIP containing the application EXE. Each Mac architecture has a DMG and a ZIP containing TypeNext.app. Application archives include the project license, third-party notices, font/runtime licenses and applicable native corresponding source. SHA256SUMS.txt covers the binary distribution assets.

This initial workflow produces unsigned Windows binaries and ad-hoc-signed Mac bundles; it does not claim Developer ID notarization or Windows certificate signing. macOS and Windows may show their normal trust prompts. The portable Windows build requires Microsoft WebView2 Runtime. Optional model downloads require a network connection for setup and then run locally. In-app automatic updating is not enabled in this release.

Model output remains optional and may be irrelevant or inaccurate despite supplied context. The real free-provider demo check reached the provider with the correct arrival reference, but its returned suggestion did not retain those facts; this release does not claim verified factual accuracy for hosted suggestions. PDF extraction reads available text rather than OCR of scanned pages.

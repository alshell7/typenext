# TypeNext 0.4.0

Organise your writing into workspaces, folders and tags, keep every version of a note, and edit selected text with AI that only proposes.

**Workspaces**

- Separate workspaces, like browser profiles, each with its own notes, folders, tags and contexts. Switch at the bottom left, or with ⌘ ⌥ 1 to 9 (Ctrl+Alt+1 to 9). Each workspace remembers its tabs.
- A shared workspace appears inside every other workspace, for a handbook, templates or reference notes.
- Each workspace can sync to its own Git repository, and can wear an icon and a colour.
- Contexts choose the workspaces that can use them. Your notebook opens as one workspace, **Personal**, exactly as before.

**Folders and tags**

- Nested folders with colours. Drag notes and folders to move them; removing a folder keeps its notes.
- Tags under each note's title, tag filters in the sidebar and a tag manager. Renaming a tag to an existing name merges the two.
- A folder can be live context for a note: every note in it, including ones you add later.

**History**

- Optional versions of every note, on this device and without Git (**Preferences → History**). Versions are kept automatically after a meaningful change, or only when you save one (⌘ ⌥ S).
- Compare any version with your note word by word, bring back single parts, or restore the whole version. Safety copies are kept before AI edits, restores and large deletions.

**Writing**

- **Edit with AI**: select text and choose Polish, Fix grammar, Rewrite, Paraphrase, Make shorter, Make longer or your own request (⌘ J). You see every change before it enters the page. Needs an active chat model.
- **Find and replace** in a note (⌘ F, ⌘ ⌥ F), with match case, whole word and patterns.
- Links show only their text until the cursor enters them. Link cards add Copy, Edit and Unlink.
- Choose your own keys for suggestions, accepting a word and AI actions (**Preferences → Shortcuts**).
- Set the most words in a suggestion, and start your instructions from twelve templates.
- A small animation plays while a model works: Orb, Spark, Bloom, Firefly and more, or none.
- Custom palette colours open a colour picker.

**Fixes**

- Selected text is readable again in dark mode, and the format bar matches the theme.
- Editor tooltips no longer show through dialogs.
- The Updates settings have proper spacing.

**Update from 0.3.0**

0.3.0 updates itself: a notice offers **Restart to update** when 0.4.0 has downloaded. Packaging is the same as in 0.3.0: unsigned Windows binaries and ad-hoc-signed Mac bundles. Updates are checked against the TypeNext update key before they install.

# Local model smoke, 2026-10-05

The real local runtime and TypeNext completion protocol worked, but the selected 0.6B model did not produce a useful model insertion in these three synthetic samples. All requests returned HTTP 200 on loopback. The model copied the existing prefix and suffix each time, and TypeNext removed those echoes. One request then used exact local recall; the other two returned no suggestion. This establishes runtime compatibility and the local-only boundary, not useful prose quality for this model.

The initial check found no model server on ports 1234, 1337, 13305 or 8080. A portable official llama.cpp Windows CPU release and one official Qwen GGUF were prepared in the ignored `artifacts/local-model-smoke` directory. Downloads totalled 658,019,365 bytes, including license texts, within the 1,000,000,000-byte limit. No installer, permanent PATH change or app configuration change was used.

The [llama.cpp server documentation](https://github.com/ggml-org/llama.cpp/blob/b11146/tools/server/README.md) documents the compatible chat endpoint, CPU limits and offline operation. The [Qwen model card](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF) documents switching thinking off and the model's license. This test used instruction-model prefix/suffix prompting; it did not test native FIM.

The isolated headless browser imported the actual TypeNext `suggest` function and default settings through the running Vite app. Each input was a new synthetic note with one enabled Markdown reference, an objective, a writing brief, and a cursor between existing prefix and suffix. Request interception verified that the correct reference passage reached the local model, that both sides of the cursor remained intact in the request, and that no Authorization header was present. Browser traffic outside the devserver and local model origins was blocked; zero hosted requests were attempted. Neither real notebook contents nor credentials were read. The web-preview fetch path was exercised, not the Tauri Rust HTTP bridge.

The garden input was prefix `At dawn, the garden` and suffix ` while the city was still asleep.`. The model returned those two pieces unchanged. During the smoke, the recall result reconstructed `At dawn, the garden held the scent of rain. while the city was still asleep.`; its sentence-ending period clashes with the existing suffix, so this was not a usable final insertion. This exposed a boundary-handling defect in mid-document recall. A subsequent regression fix withholds a recalled sentence ending before an existing lowercase same-line continuation, rather than removing source punctuation or inventing a bridge. Exact source matches across an existing suffix, end-of-note punctuation, and capitalized or newline next-sentence boundaries are retained. Service tests cover the observed failure and those preserved cases. No model request was repeated after this fix, so the smoke results above remain the original observations. The river sample required a missing reason before ` and stayed until the light faded.`. The reading-group reference explicitly specified `6:30 pm on Thursday in the library`; the model added none of that information.

All three cases completed without a transport error, and exactly three generation POSTs were sent. Empty output after echo removal did not trigger a cloud fallback. The first nonempty result was copied reference text, not generated model prose. It must not be counted as evidence of model completion quality. The samples were never written into a real notebook or automatically accepted.

The runtime's own log reported model load and listening at about 0.741 seconds after process start. The first external health observation, 33.248 seconds after launch, confirmed readiness; it was not a continuously measured startup probe. Peak process working set was 941,813,760 bytes, about 898 MiB. The first generation had no server prompt cache; the two warm requests reused 184 prompt tokens. These are single observations on one host. The downloaded model had already been hashed, OS disk caches were not cleared, and no repeated latency or quality benchmark was performed.

The helper was stopped after the smoke. Cleanup verified its executable path and exact process start time before terminating it. Port 1234 became unreachable, while the existing TypeNext devserver on port 1420 still returned HTTP 200. The ignored model, portable runtime, license texts and synthetic `report.json` remain available for review; the helper does not restart automatically. The smoke itself did not change app settings, tests or dependencies; the separately authorized recall fix changed the completion service and its regression tests afterward.

This result supports using a local server with the current completion service, while showing that Qwen 0.6B Q8_0 should not be presented as a proven default for this prose task. A larger instruction model or a different constrained prompt needs its own evaluation. Native FIM, partial-word quality, multilingual suggestions, longer notes and macOS runtime performance remain untested by this three-request sample.

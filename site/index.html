Begin with your intention.

Name a note and add a little background. Your first line can set the objective.

Bring the details that matter.

Keep folders, files, websites and live notes in a context library, then attach the references each note needs. Preview the text and choose what to include.

Keep only what fits.

Tab accepts a continuation. Ctrl or Command plus Right accepts a word. Escape lets the thought go.

Your writing stays with you.

Start with short offline writing prompts, or recall phrases from your writing and references. Attachments are optional. Ctrl or Command plus Space opens a few ways forward; a local model can provide richer continuations.

OpenRouter, OpenAI, Anthropic, and custom endpoints are optional. Choose an external model explicitly to keep its suggestions active. The app explains what is shared and lets you return to local at any time.

Make it your own.

TypeNext is licensed under AGPL-3.0-or-later. The app uses Tauri, React, and a small Markdown editor. Download a small optional writing model inside TypeNext, or connect your own local server. Optional Whistle dictation turns speech into an editable transcript on your device.

To build the desktop app, install Node.js 22.13 or later, stable Rust, and the Tauri prerequisites for your system.

git clone https://github.com/alshell7/typenext.git
cd typenext
npm ci
npm run tauri:dev

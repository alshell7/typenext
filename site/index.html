Begin with your intention.

Name a note and add a little background. Your first line can set the objective.

Bring the details that matter.

Attach files or a website, or link another note as live context. Preview the text and choose what to include.

Keep only what fits.

Tab accepts a continuation. Ctrl or Command plus Right accepts a word. Escape lets the thought go.

Your writing stays with you.

Local recall works without a model, using phrases from your references or earlier writing. Connect a local model server for new, context-aware continuations.

OpenRouter, OpenAI, Anthropic, and custom endpoints are optional. Each external suggestion needs a separate request and a clear explanation of what will be sent.

Make it your own.

TypeNext is licensed under AGPL-3.0-or-later. The app uses Tauri, React, and a small Markdown editor. Local models are managed by your chosen server.

To build the desktop app, install Node.js 22.13 or later, stable Rust, and the Tauri prerequisites for your system.

git clone https://github.com/alshell7/typenext.git
cd typenext
npm ci
npm run tauri:dev
